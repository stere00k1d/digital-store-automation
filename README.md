# AI Digital Store Automation

MVP проекта автоматизации цифрового магазина с помощью n8n, локальной AI-модели Ollama (Qwen3:4b) и Google Sheets.

## Что умеет
- Понимает сообщения покупателей с помощью AI.
- Определяет товар и количество.
- Отвечает на вопросы о наличии.
- Проверяет остатки перед оформлением заказа.
- Записывает заказы в Google Sheets.

## Технологии
- n8n — автоматизация процессов.
- Ollama + Qwen3:4b — обработка сообщений.
- Google Sheets — учёт заказов.
- Docker — локальный запуск n8n.

## Статус
Локальный MVP. Реальная оплата, API поставщика и автоматическая выдача цифровых товаров пока не подключены.

## Workflow
Экспорт схемы находится в папке workflows/customer-support.json.
